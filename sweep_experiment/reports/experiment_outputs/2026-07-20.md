## Valid findings so far (12-config grid + oracle, N=998 — NOT dependent on the bugs)

- Population fixed-budget TTA is FLAT: all 12 configs within 0.11 dB PSNR
  (19.372–19.486), SSIM ~0.688, FVD 65–69, FID 12.3–12.5. `S2` (train 15s) ==
  `S20` (train 128s) at population level -> 8x cheaper for same quality.
- Per-video oracle uplift is real but modest/tail-driven: oracle-best 19.844 dB,
  +0.382 dB vs fixed S10_LR5e3, bootstrap 95% CI [+0.337, +0.429] (excludes 0);
  median only +0.144 dB.
- Paradox: the WORST population config `S20_LR1e2` (19.372) is the MOST-picked
  per-video oracle winner (30.6%, +0.544 dB when it wins). Strong case for
  per-video budget routing over any fixed budget.
- PSNR-oracle routing wrecks distributional quality: oracle FVD=383.9 (N=200
  cache) vs ~66 per-config -> routing objective matters (PSNR router != FVD router).
